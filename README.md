# homebrew-dico

```sh
brew install --cask mechanicpanic/dico/dico
brew upgrade --cask dico
```

Installs **Dico.app** (the popup, ⌥D) and the `dico` command. The app is signed ad-hoc: pass `--no-quarantine` to skip the one-off Gatekeeper prompt, or open it once via System Settings ▸ Privacy & Security ▸ Open Anyway.
